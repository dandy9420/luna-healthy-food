# Luna Healthy Food

Luna Healthy Food website and ordering application for Terra Eden Bali.

## Current application configuration

- Delivery ordering by Luna Healthy Food via WhatsApp
- Customer checkout: full name, WhatsApp number, Google Maps location link
- Delivery fee calculated from route distance
- WhatsApp order message follows the selected language
- Languages: Bahasa Indonesia, English, Русский, Tiếng Việt
- Profile: Favorites, Help & support, Language
- Compact Terra Eden address and opening-hours footer
- Customer Reviews carousel
- Luna Wellness Journal carousel
- External ordering links: GoFood, ShopeeFood, GrabFood

## Source package

The latest modified source is prepared as the `luna-site/` package from the Claude Artifact export.
